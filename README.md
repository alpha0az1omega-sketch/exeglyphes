# EXEGLYPHES

Self-executing visual forms. Each element is a real-time mathematical computation.

## What is an exeglyphe?

A single HTML file that contains:
- One or more mathematical formulas
- A canvas that executes them live
- A SHA-256 signature

No image. No video. A computation that shows itself.

## Versions

### 001 — Rule 110
Cellular automaton. Turing-complete.
The visual is the computation. Remove the rule, the image disappears.

[Open](versions/001_regle110/)

### 002 — Projects in Live Calculation
Each project is a parametric formula. 9 curves, 9 computations, 9 colors.
The spectator sees the project without reading the code.

[Open](versions/002_projets_calcul/)

## Why it's unique

- Each visual element IS a computation
- Works without a server
- Shareable by SMS, email, or link
- Carries its own cryptographic signature
