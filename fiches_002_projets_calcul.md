# EXEGLYPHE 002 — Projets en Calcul Direct

## Ce que c'est
Chaque projet du sanctuaire devient une FORMULE qui s'exécute.
9 courbes, 9 formules différentes, 9 couleurs.

## Pourquoi
Montrer que les projets peuvent s'auto-représenter.
Un scientifique voit le projet SANS lire le code.

## Comment
- 9 projets, chacun avec une formule paramétrique
- Chaque formule : r(t) = f(t)
- La courbe est tracée point par point (400 points)
- Un point vivant parcourt la courbe
- Le compteur de calculs augmente en direct

## Formules utilisées
- adn       : r(t) = 80 + 40·sin(3t)
- flash     : r(t) = 60 + 30·cos(5t)
- conscience: r(t) = 50 + 50·sin(t/2)·cos(2t)
- coffre    : r(t) = 90 + 20·sin(7t)·cos(t)
- preuve    : r(t) = 70 + 30·|sin(2t)|
- Horizon   : r(t) = 100 + 40·sin(t)·sin(3t)
- cockpit   : r(t) = 40 + 60·sin(4t)²
- vif       : r(t) = 75 + 25·cos(6t)
- copilote  : r(t) = 85 + 35·sin(2t)·cos(4t)
